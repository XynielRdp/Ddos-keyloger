# ⚜️ DANIEL NESIA - VIP PANEL ACTIVATION SYSTEM

![Daniel Nesia](https://files.catbox.moe/kivdno.jpg)

**DANIEL NESIA V80.0** adalah sistem aktivasi panel otomatis berbasis web yang dirancang khusus untuk kemudahan transaksi layanan digital. Dengan antarmuka **Royal Gold VIP**, website ini memberikan pengalaman eksklusif bagi pelanggan sebelum melakukan aktivasi melalui WhatsApp.

---

## 💎 Fitur Utama

- **Royal Gold UI/UX**: Desain mewah dengan kombinasi warna Deep Obsidian dan Gold Leaf.
- **Animated Background**: Efek partikel emas mengalir (Gold Dust Aura) menggunakan `particles.js`.
- **Dynamic Price Tag**: Harga berubah secara real-time sesuai durasi paket yang dipilih.
- **No Prefix Input**: Input nama result murni sesuai keinginan user tanpa tambahan karakter otomatis.
- **WhatsApp Integration**: Format pesanan otomatis yang rapi dan siap kirim untuk aktivasi cepat.
- **Glassmorphism Design**: Efek blur transparan yang modern dan ringan.

---

## 🛠️ Spesifikasi Teknis

- **Frontend**: HTML5, CSS3 (Custom Styles)
- **Framework**: Bootstrap 5.3 (Grid & Responsiveness)
- **Animation**: Particles.js (Aura Animation)
- **Icons**: FontAwesome 6.4.0
- **Typography**: Cinzel (Header) & Plus Jakarta Sans (Body)

---

## 🚀 Cara Penggunaan / Instalasi

1. **Persiapan File**: 
   Simpan kode utama ke dalam file bernama `index.html`.
   
2. **Koneksi Internet**:
   Pastikan perangkat terhubung internet karena website ini mengambil library CSS/JS dari CDN (Bootstrap, FontAwesome, Particles.js).

3. **Cara Menjalankan**:
   Klik kanan pada file `index.html` dan pilih **Open with Browser** (Chrome/Safari/Edge).

4. **Kustomisasi**:
   Untuk mengganti nomor WhatsApp, cari bagian `https://wa.me/6285692069556` dan ganti nomornya dengan nomor tujuan Anda.
